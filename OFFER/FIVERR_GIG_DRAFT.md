## Gig description

Is your AI automation failing after an API change, model retirement, expired credential, or a broken scheduled workflow?

I will inspect one existing Python or GitHub Actions workflow, trace one agreed failure from its logs and source code, implement a bounded repair, and add regression tests so the same defect is less likely to return.

### What you receive

- A focused review of one existing workflow
- Root-cause findings based on source code and sanitized logs
- One agreed bug or integration repair
- Up to five focused regression tests
- Safer error handling and publishing controls where relevant
- A Git branch or pull request
- A concise handover and rollback note

### Good fit

- Python automation
- GitHub Actions scheduled jobs
- LLM API integration failures
- AI content pipeline reliability
- Model ID migrations
- Missing error handling and regression tests
- Safe human approval gates before publishing

### Important boundaries

This is a repair service for an existing workflow, not unlimited development. Paid API usage, paid hosting, third-party subscriptions, and external platform charges are not included. You keep credentials in your own secret manager. Never send passwords, API keys, OAuth tokens, or private customer data in chat.

I do not promise revenue, views, rankings, or guaranteed platform approval. Any production deployment or publishing action requires your explicit approval.

## FAQ

**Do you need my API key?**  
No. Keep credentials in your own GitHub or provider secret manager. Share only variable names and sanitized error output.

**Will you publish content or send messages?**  
No, not by default. External actions remain disabled unless you separately approve them.

**Can you guarantee that every AI provider will work?**  
No. Provider access, account eligibility, rate limits, model availability and billing are controlled by the provider. I will verify the agreed test path and document any external blocker.

**Do you build a new AI agent from scratch?**  
This gig is for a bounded repair to an existing workflow. New product builds require a separate scope.
