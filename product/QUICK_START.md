# Admission Desk Lite — Quick Start

**Product type:** Offline-first digital workflow tool for coaching institutes and tuition centres.
**Version:** 1.0
**Language:** Hindi + English interface.
**Price status:** Not yet validated. No price or sales claim is being represented as proven.

## What it does
- Records a parent/contact person's name, phone, course/class, enquiry source, pipeline stage and next follow-up date.
- Shows total enquiries, active follow-ups, demo schedules and overdue follow-ups.
- Supports search, stage filtering, CSV export/import and a consent-gated WhatsApp message draft.
- Runs in a modern browser without login, server, database subscription, analytics or external JavaScript.

## Start
1. Download `admission-desk-lite.html`.
2. Open it in Chrome, Edge or Firefox.
3. Add one test enquiry using your own test contact details.
4. Set a next follow-up date and stage.
5. Export a CSV backup and test importing that backup.
6. Use WhatsApp only when the contact has agreed to be contacted. Review the message and press Send yourself.

## Important limitations
- Data stays in that browser's local storage. It is not synced across staff, browsers or devices.
- Clearing browser site data can erase records. CSV backups are essential.
- It is not a CRM, does not send messages automatically, and does not integrate with WhatsApp Business API.
- No student marks, health information, identity documents, or other sensitive details should be stored.
- The institute is responsible for lawful collection, notices, consent, access control, retention and deletion of contact information.
- A WhatsApp link opens a draft only. It does not send a message.
- This is a pilot build, not a certified or audited production system.
